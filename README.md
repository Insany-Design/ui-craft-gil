# Fundamentos de UI mobile

Apresentação educacional estática em português. Abra `dist/index.html` ou sirva o diretório `dist` com qualquer servidor estático. Sem dependências, coleta de dados ou autenticação.

37 temas, 37 diagramas SVG originais, 5 capítulos, checklist, exercício e referências. O aprofundamento de cada tema fica disponível em um controle expansível. Use o índice ou anterior/próximo. Atalhos opcionais: Alt + seta esquerda/direita. Escape fecha imagens ampliadas e o índice mobile.

O checklist funciona apenas durante a sessão atual. Os diagramas são exemplos didáticos do aplicativo fictício Trilha, não resultados de testes medidos.
